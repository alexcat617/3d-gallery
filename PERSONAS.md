# Personas

Two lenses used in every FEAT file (`P1` / `P2`). Draft — refine with real visitor info.

## P1 — Riley, hiring reviewer (desktop)

| | |
|---|---|
| Context | Design lead or recruiter opening a portfolio link between meetings. Laptop, Chrome, trackpad or mouse. |
| Time | 3–5 minutes. |
| Wants | See the strongest work fast, understand the story behind each piece, judge craft. |
| Fears | Long load with a blank screen; getting lost; motion sickness; can't find the "real" info. |
| Needs from us | Fast first frame, obvious controls hint, Escape always works, a list view to jump straight to pieces. |

## P2 — Mia, mobile visitor (phone)

| | |
|---|---|
| Context | Taps a link from social or scans a QR code (e.g. at a venue showing the work). iPhone or Android, one hand, possibly weak signal. |
| Time | 1–2 minutes. |
| Wants | Something delightful to poke at; tap a piece and read about it. |
| Fears | Tiny controls, janky frame rate, battery drain, no idea how to move. |
| Needs from us | Tap-to-move or joystick, 44px targets, lighter asset budget, readable cards. |
